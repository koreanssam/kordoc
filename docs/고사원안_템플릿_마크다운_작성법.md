# 고사원안 템플릿 Markdown 작성법

이 문서는 Kordoc의 `고사원안` 프리셋으로 2단 편집 HWPX 시험지를 만들 때 사용하는
Markdown 작성 규칙을 설명합니다.

```bash
kordoc generate 고사원안.md -o 고사원안.hwpx --preset 고사원안
```

## 1. 문서의 기본 구성

고사원안 Markdown은 다음 순서로 작성합니다.

1. YAML 머리정보
2. 지문 묶음
3. 지문에 딸린 문항
4. 필요한 경우 `<보기>` 상자
5. 다음 지문과 문항

기본 뼈대는 다음과 같습니다.

```markdown
---
시험일시: 2026.4.28.(화) 2교시
학교: 영산중학교
학년: 2
과목: 국어
과목코드: 01
시험명: 2026학년도 1학기 1차시험
전체쪽수: 6
전체문항수: 9
만점: 100
서술형점수: 100
---

## [서술형 1] 다음 글을 읽고, 아래의 물음에 답하시오.

지문을 입력합니다.

# 서술형 1-1. 첫 번째 질문을 입력합니다. (5점)

# 서술형 1-2. 두 번째 질문을 입력합니다. (5점)
```

## 2. YAML 머리정보 작성법

문서 맨 위의 `---`와 `---` 사이에 시험 정보를 작성합니다.

```yaml
---
시험일시: 2026.4.28.(화) 2교시
학교: 영산중학교
학년: 2
과목: 국어
과목코드: 01
시험명: 2026학년도 1학기 1차시험
전체쪽수: 6
전체문항수: 9
만점: 100
서술형점수: 100
---
```

각 항목의 의미는 다음과 같습니다.

| 항목 | 입력 예 | 적용 위치 |
|---|---|---|
| `시험일시` | `2026.4.28.(화) 2교시` | 시험지 왼쪽 위 |
| `학교` | `영산중학교` | 시험지 오른쪽 위 |
| `학년` | `2` | 시험지 왼쪽 아래 |
| `과목` | `국어` | 시험지 가운데 |
| `과목코드` | `01` | 과목명 아래 |
| `시험명` | `2026학년도 1학기 1차시험` | 과목명 아래 |
| `전체쪽수` | `6` | 머리표의 전체 쪽수 |
| `전체문항수` | `9` | 머리표 및 안내 문구 |
| `만점` | `100` | 만점 안내 |
| `서술형점수` | `100` | 서술형 배점 안내 |

`전체쪽수`는 머리표에 표시할 값입니다. 실제 쪽수는 지문 길이와 문항 수에 따라 달라질 수
있으므로 최종 HWPX를 확인한 후 값을 맞추는 것이 좋습니다.

## 3. 지문 입력 규칙

지문 묶음의 제목은 반드시 `##`로 시작합니다.

```markdown
## [서술형 1] 다음 글을 읽고, 아래의 물음에 답하시오.
```

그 아래에 이어지는 일반 문단은 모두 해당 지문의 본문으로 처리됩니다.

```markdown
## [서술형 1] 다음 글을 읽고, 아래의 물음에 답하시오.

자라면 뭐가 되고 싶니

의자가 되고 싶니

누군가의 책상이 되고 싶니
```

지문 작성 시 주의 사항:

- 지문 제목에는 `##`를 사용합니다.
- 실제 질문에는 `#` 하나를 사용합니다.
- 지문의 각 문단 사이에는 빈 줄을 넣는 것이 안전합니다.
- 시처럼 행 구분이 중요한 글은 각 행을 별도 줄로 작성합니다.
- 지문 안에서는 `#` 또는 `##`로 시작하는 일반 문장을 사용하지 않습니다.
- 지문이 끝난 뒤 첫 번째 문항을 쓰면 해당 지문 묶음이 종료됩니다.

### 시 지문 예시

```markdown
## [서술형 1] 다음 시를 읽고, 아래의 물음에 답하시오.

자라면 뭐가 되고 싶니

의자가 되고 싶니

누군가의 책상이 되고 싶니

바람의 춤을 따라 흔들리고 있구나
```

### 소설·설명문 지문 예시

```markdown
## [서술형 2] 다음 글을 읽고, 아래의 물음에 답하시오.

(가)

첫 번째 서술자의 글을 입력합니다.

(나)

두 번째 서술자의 글을 입력합니다.
```

### 대화 지문 예시

```markdown
## [서술형 3] 다음 대화를 읽고, 아래의 물음에 답하시오.

배경: 쉬는 시간, 교실 안.

수아: 오늘 수행평가 준비는 잘 되고 있어?

하은: 아직 자료를 정리하고 있어.

수아: 필요한 부분이 있으면 같이 살펴보자.
```

## 4. 문항 입력 규칙

질문은 반드시 `#` 하나로 시작합니다.

```markdown
# 서술형 1-1. ‘시적 화자’의 정의를 쓰시오. (3점)
```

문항은 다음 형태로 작성하는 것을 권장합니다.

```text
# 서술형 문항번호. 질문 내용 (배점)
```

예:

```markdown
# 서술형 1-1. 윗글의 중심 내용을 쓰시오. (5점)

# 서술형 1-2. 글쓴이의 의도를 설명하시오. (5점)

# 서술형 2. 다음 대화를 읽고 물음에 답하시오.
```

문항 작성 시 주의 사항:

- `#` 뒤에 반드시 한 칸을 띄웁니다.
- 문항 번호 뒤에는 마침표를 붙입니다.
- 배점은 문장 끝에 `(5점)`처럼 작성합니다.
- 문항과 문항 사이에는 빈 줄을 넣습니다.
- 문항 번호는 `1`, `1-1`, `1-2`, `2-1` 형식을 모두 사용할 수 있습니다.
- `<보기>`를 소개하는 상위 문항에는 배점을 생략할 수 있습니다.

## 5. `<보기>` 상자 입력 규칙

`<보기>` 상자는 `:::보기`와 `:::` 사이에 작성합니다.

```markdown
:::보기
보기 안에 들어갈 내용을 작성합니다.
:::
```

실제 예시는 다음과 같습니다.

```markdown
# 서술형 6. 다음은 윗글을 읽고 학생들이 나눈 대화이다.

:::보기
지민: 이 글의 ㉠에서는 ‘정의’의 방법이 사용되었어.
수현: ㉡에서는 일정한 기준에 따라 나누었으니 ‘구분’이 사용되었어.
민재: ㉢에서는 원인과 결과가 드러나므로 ‘인과’가 사용되었어.
하은: ㉣에서는 두 대상의 차이를 설명하고 있어.
:::

# 서술형 6-1. 설명 방법을 잘못 이해한 친구를 찾아 쓰시오. (5점)

# 서술형 6-2. 그 설명이 잘못된 이유를 쓰시오. (5점)
```

`<보기>` 작성 시 주의 사항:

- 시작 표시는 `:::보기`로 정확히 작성합니다.
- 끝 표시는 `:::`만 작성합니다.
- 시작과 끝 표시는 각각 별도 줄에 둡니다.
- `<보기>`라는 글자는 직접 입력하지 않아도 템플릿이 자동으로 표시합니다.
- 보기 안의 각 발언이나 항목은 별도 줄로 작성합니다.
- `:::보기` 안에서는 제목 표시인 `#`, `##`를 사용하지 않습니다.
- 하나의 보기 상자가 끝난 다음 문항을 작성합니다.

### 논증 자료 `<보기>` 예시

```markdown
# 서술형 7. 다음 <보기>를 읽고, 아래의 질문에 답하시오.

:::보기
(가) 우리 동네 길고양이 ‘나비’는 츄르를 아주 좋아한다.
(나) 친구가 키우는 고양이 ‘치즈’도 츄르를 잘 먹는다.
(다) 영상 속 여러 고양이도 츄르를 보면 달려든다.
결론: 그러므로 세상의 모든 고양이는 츄르를 좋아할 것이다.
:::

# 서술형 7-1. 위 글에 사용된 논증 방법을 쓰시오. (6점)

# 서술형 7-2. 해당 논증 방법의 정의를 서술하시오. (6점)
```

## 6. 여러 지문과 문항을 배치하는 방법

새로운 지문이 시작될 때마다 새로운 `##` 제목을 사용합니다.

```markdown
## [서술형 1] 다음 시를 읽고 물음에 답하시오.

첫 번째 지문입니다.

# 서술형 1-1. 첫 번째 질문입니다. (5점)

# 서술형 1-2. 두 번째 질문입니다. (5점)

## [서술형 2] 다음 소설을 읽고 물음에 답하시오.

두 번째 지문입니다.

# 서술형 2-1. 세 번째 질문입니다. (5점)
```

Kordoc은 작성된 순서대로 지문, 문항, `<보기>`를 배치하고 2단으로 흘려보냅니다.
작성자가 직접 단 나누기나 쪽 나누기를 입력할 필요는 없습니다.

## 7. 권장하지 않는 작성 방식

다음과 같은 방식은 피하는 것이 좋습니다.

### 지문 제목에 `#` 하나만 사용

```markdown
# [서술형 1] 다음 글을 읽으시오.
```

이렇게 작성하면 지문 제목이 아니라 일반 문항으로 처리됩니다. 지문 제목은 `##`를
사용해야 합니다.

### 질문에 `##` 사용

```markdown
## 서술형 1-1. 질문 내용 (5점)
```

이렇게 작성하면 새로운 지문 묶음으로 처리됩니다. 질문은 `#` 하나를 사용합니다.

### `<보기>` 종료 표시 누락

```markdown
:::보기
보기 내용

# 서술형 1-1. 질문 내용 (5점)
```

종료 표시 `:::`가 없으면 뒤의 문항까지 보기 내용으로 들어갈 수 있습니다.

### HTML 표를 직접 작성

새 시험지를 직접 작성할 때는 `<table>` 대신 `:::보기` 문법을 사용합니다.
HTML 표는 기존 HWP를 Kordoc으로 추출했을 때의 왕복 복구용으로만 자동 인식됩니다.

## 8. 전체 작성 예시

```markdown
---
시험일시: 2026.4.28.(화) 2교시
학교: 영산중학교
학년: 2
과목: 국어
과목코드: 01
시험명: 2026학년도 1학기 1차시험
전체쪽수: 2
전체문항수: 3
만점: 20
서술형점수: 20
---

## [서술형 1] 다음 글을 읽고, 아래의 물음에 답하시오.

봄이 오면 산과 들에 새로운 잎이 돋는다.

사람들은 따뜻한 햇살을 맞으며 새로운 계절을 준비한다.

# 서술형 1-1. 윗글의 중심 내용을 쓰시오. (5점)

# 서술형 1-2. 글에 드러난 계절의 특징을 쓰시오. (5점)

## [서술형 2] 다음 글을 읽고, 아래의 물음에 답하시오.

민수와 지수는 학교 도서관 이용 방법에 관해 이야기를 나누었다.

# 서술형 2. 다음은 두 학생이 나눈 대화이다.

:::보기
민수: 도서관에서는 사용한 책을 제자리에 꽂아야 해.
지수: 위치를 모르면 반납함에 넣는 것이 더 안전해.
:::

# 서술형 2-1. 두 학생의 의견 차이를 쓰시오. (10점)
```

## 9. 생성 후 확인할 사항

HWPX를 생성한 뒤 다음 항목을 확인합니다.

- 시험일시, 학교, 학년, 과목 및 과목코드
- 시험명, 전체쪽수, 전체문항수
- 지문 제목과 지문 내용
- 문항 번호와 배점
- `<보기>` 상자 안의 줄바꿈
- 2단 배치와 단 사이 간격
- 표나 지문이 쪽 경계에서 잘리지 않는지
- 마지막 확인 사항과 쪽번호

Kordoc 미리보기는 순수 재조판 결과이므로 한컴오피스의 최종 쪽수와 줄바꿈이 조금 다를 수
있습니다. 최종 배포 전에는 생성된 HWPX를 한컴오피스 또는 실제 사용할 뷰어에서도
확인하는 것이 좋습니다.
